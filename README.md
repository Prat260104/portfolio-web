# Prateek Rai — UI/UX Designer & Full-Stack Developer Portfolio

Welcome to my portfolio! I'm **Prateek Rai**, a UI/UX Designer & Full-Stack Developer specializing in crafting intuitive digital experiences and building scalable, high-performance web applications.

## 🛠 Tech Stack

This portfolio is built using modern web technologies:

- [**Vue.js 3**](https://vuejs.org/) (Composition API & TypeScript)
- [**GSAP**](https://greensock.com/gsap/) (Advanced Web Animations & ScrollTrigger)
- [**Tailwind CSS**](https://tailwindcss.com/) (Responsive Utility Styling)
- [**Lenis**](https://lenis.darkroom.engineering/) (Smooth Inertial Scrolling)
- [**Vite.js**](https://vitejs.dev/) (High-performance Build Tooling)

## 🔍 Portfolio Sections

- **Loading Screen**: Seamlessly animated intro with custom brand typography.
- **Hero**: Dynamic introductory header with SVG typography and magnetic physics.
- **Services**: Highlights in UI/UX Design, Full-Stack Development, and Performance Optimization.
- **Marquee**: Infinite interactive marquee ticker.
- **Selected Works**: Interactive project showcase with dynamic video previews and sticky indexing.
- **About Me**: Narrative bio and design/development philosophy.
- **Testimonials**: Interactive quote slider featuring institutional leadership and GSoC mentors.
- **Contact Me**: Interactive contact hub with globe widget, direct mailto CTA, and timezone clock.

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/Prat260104/portfolio-web.git

# Navigate to project directory
cd portfolio-web

# Install dependencies
npm install

# Run development server
npm run dev
```
